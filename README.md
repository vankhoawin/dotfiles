# dotfiles

Personal shell configuration and scripts.

## Contents

- `zsh/.zshrc` - Zsh configuration (Oh My Zsh + plugins)
- `scripts/` - Custom shell scripts
- `install.sh` - Setup script for new machines

## Setup

```bash
git clone https://github.com/vankhoawin/dotfiles.git ~/repos/dotfiles
cd ~/repos/dotfiles
./install.sh
```
